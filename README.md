# 清水混凝土计算器

清水混凝土（Béton Brut）外观风格的网页计算器：面板带分格缝与对拉螺栓孔，按键呈现浇筑批次色差，支持触屏与键盘操作。

## ✨ 功能特性

- 基础四则运算与百分比，支持退格，AC / C 按输入状态自动切换
- 连按 `=` 可重复上一次运算；除以零给出「不能除以零」错误提示
- 12 位有效精度，千分位分组显示，超大 / 极小数自动转科学计数法
- 键盘全支持：数字、`+ - * /`、`Enter`/`=`、`Backspace`、`Escape`、`%`
- 显示区字号自适应缩小，长数字不会溢出截断
- 手机端满屏适配（含安全区），`Calculator` 核心类独立封装并支持 CommonJS 导出，便于测试

## 🚀 使用方法

纯静态单文件页面，无需构建、无需联网。直接用浏览器打开 `index.html`，鼠标点击或键盘输入均可。

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript（单文件，零依赖）
- CSS：SVG feTurbulence 噪点模拟混凝土颗粒、渐变与内阴影塑造立体按键

## 📁 目录结构

- `index.html` — 界面样式、计算核心类与 DOM 绑定
